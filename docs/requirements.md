# 바로바로 화면 요구사항

2026-11-28에 공유한 팀 요구사항표에서 RQ-ID·요구사항명·내용을 옮겼다. 번호는 다른 문서와 이슈에서 그대로 참조한다. 개발 진행 상황은 각 작업 이슈에서 확인한다. 관리자 대시보드 제안과 번호 차이는 [관리자 웹 인수인계](admin.md)에 정리했다.

## 가입·인증

| RQ-ID | 요구사항 | 사용자가 확인할 동작 |
| --- | --- | --- |
| AC-01 | 자체 회원가입 | 아이디와 비밀번호를 정해 회원으로 가입할 수 있다. |
| AC-02 | 카카오 계정 연동 | 카카오 계정을 기존 아이디에 연동하여 로그인할 수 있다. |
| AC-03 | 로그인·로그아웃 | 가입한 계정으로 로그인한다. 로그아웃하면 그 기기에서 내 약속을 더 볼 수 없다. |
| AC-04 | 아이디·비밀번호 찾기 | 아이디는 찾고, 비밀번호는 재설정 할 수 있게 한다. |
| AC-05 | 본인인증 | 가입할 때 본인인증을 한 번 한다. 인증된 실명이 차용증의 당사자 이름으로 쓰인다. |
| AC-06 | 가입 제한 | 미성년자는 가입할 수 없고, 한 사람은 계정을 하나만 가진다. |
| AC-07 | 약관 동의 | 가입할 때 필수 약관과 선택 항목을 구분하여 동의한다. |
| AC-08 | 계좌 연결 및 인증 | 본인 명의 계좌 하나를 연결해 송금과 상환에 쓴다. 연결할 때 그 계좌로 보낸 1원의 입금자명을 입력해 내 계좌가 맞는지 확인한다. 송금·상환할 때 입력할 PIN번호를 설정한다. |
| AC-09 | 계좌 PIN번호 재설정 | PIN번호 인증 5회 실패 시 본인 인증 후 PIN번호를 재설정한다. |

## 내 정보

| RQ-ID | 요구사항 | 사용자가 확인할 동작 |
| --- | --- | --- |
| MY-01 | 회원 탈퇴 | 로그인한 본인만 탈퇴할 수 있다. 진행중인 계약이 있으면 탈퇴할 수 없고, 그 이유를 안내받는다. |
| MY-02 | 계좌 정보 변경 | 연결 계좌와 인증 상태를 확인하고 본인 명의 계좌로 변경한다. 새 계좌를 연결했다고 이미 서명한 차용증의 계좌까지 자동으로 바뀌지는 않도록 구분한다. |
| MY-03 | 내 정보 변경 | 로그인한 사용자는 휴대폰 번호를 재확인 절차를 거쳐 변경할 수 있다. 본인인증으로 확인된 실명은 일반 정보 수정으로 변경할 수 없다. |
| MY-04 | 종료된 계약 보기 | 종료된 계약을 검색하고 해당 계약의 원문, 변경 버전과 상환 영수증을 조회한다. 약정서 PDF를 내려받을 수 있다. |
| MY-05 | 로그인 비밀번호 변경 | 로그인한 사용자가 기존 비밀번호를 확인한 뒤 새 비밀번호로 변경한다. 기존 비밀번호를 모르면 비밀번호 재설정으로 이동한다. |
| MY-06 | 상환 알림 설정 | 상환일 며칠 전에 알림을 받을지와 알림 시간을 설정한다. 개인의 미리 알림 설정은 상대방에게 공개하지 않는다. |

| CN-06 | 연결·진행 기록 | 체결한 뒤에 어떤 방식으로, 언제 어떤 단계를 거쳤는지 기록을 본다. |

## 대여 송금

| RQ-ID | 요구사항 | 사용자가 확인할 동작 |
| --- | --- | --- |
| TR-01 | 대여 송금 | 빌려주는 사람은 차용증에 적힌 금액을 차용증에 적힌 상대에게 앱에서 바로 보낸다. 송금 확정 전에 PIN번호를 입력받는다. |
| TR-02 | 돈 받기 | 빌린 사람은 돈이 들어오면 알림을 받고 첫 상환일을 안내받는다. |
| TR-03 | 송금 전 취소 | 서명은 했지만 아직 돈을 보내지 않았다면 한 사람이 취소를 요청하고 상대가 동의해 약속을 취소할 수 있다. 송금이 처리 중이면 결과가 나온 뒤 취소할 수 있는지 안내받는다. 취소된 차용증과 기록은 지워지지 않고 '취소됨'으로 남으며, 두 사람 모두 알림을 받는다. |
| TR-04 | 송금 기한 안내 | 서명한 뒤 24시간 안에 돈이 보내지지 않으면 두 사람 모두 알림을 받고, 빌릴 사람은 상대 동의 없이 약속을 취소할 수 있다. 송금과 취소가 동시에 일어나도 둘 중 하나만 처리된다. |

## 비기능(품질)

| RQ-ID | 요구사항 | 사용자가 확인할 동작 |
| --- | --- | --- |
| NFR-01 | 문서가 바뀌지 않음 | 서명한 차용증이 나중에 바뀌지 않았는지 확인할 수 있다. |
| NFR-02 | 돈이 두 번 나가지 않음 | 같은 송금이나 상환이 두 번 처리되지 않는다. |
| NFR-03 | 당사자만 봄 | 계약의 상세 조건, 차용증 원문과 영수증은 계약 당사자 두 사람만 조회할 수 있다. 관리자는 부여된 권한에 따라 계약 식별자·진행 상태·처리 시각 등 정해진 운영 정보만 조회한다 |
| NFR-04 | 개인정보 보호 | 휴대폰 번호와 계좌번호는 일부를 가려서 보여 준다. 주민등록번호는 받지 않는다. |
| NFR-05 | 기록이 남음 | 누가 언제 열람, 서명, 송금, 변경했는지 기록이 남고, 지우거나 고칠 수 없다. |
| NFR-06 | QR 안전 | QR은 한 번만 쓸 수 있고 정해진 시간 안에 만료된다. QR에는 개인정보와 차용증 내용이 들어 있지 않다. |
| NFR-07 | 정직한 안내 | 대면으로 작성하든 비대면으로 작성하든 효력이 다르다고 안내하지 않는다. 본인인증이 테스트 연동임을 밝힌다. |
| NFR-08 | 로그인한 사람만 사용 | 회원가입, 로그인, 아이디 찾기, 비밀번호 재설정, 약관 열람과 원격 초대 안내 화면을 제외한 기능은 로그인해야 사용할 수 있다. 원격 초대의 계약 내용 확인·응답·서명은 로그인과 지정 수신자 확인을 완료한 사람만 할 수 있다. |
| NFR-11 | 처리 중 표시 | 서명, 송금, 갚기, 제안 보내기는 처리 중임이 보이고 그동안 다시 누를 수 없다. |
| NFR-12 | 실패 안내 | 실패하면 이유와 다음에 할 일(다시 시도, 조건 고치기)을 알려 준다. |
| NFR-13 | 관리자 권한 보호 | 서버가 모든 관리자 요청의 로그인 상태와 관리자 권한을 확인한다. 일반 회원은 관리자 화면이나 API에 직접 접근해도 정보를 조회할 수 없다. |
