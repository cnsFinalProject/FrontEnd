## 시안에서 보완한 점

- 시안의 고정 HTML에서는 두 홈의 원금이 30만/20만 원으로 달랐지만 앱에서는 같은 계약 원장으로 계산한다.
- 변경 수락 후 완료 화면으로 넘어가는 축약 대신 실제로 양쪽 재서명 후 새 버전을 적용한다.
- 원문을 읽기 전에 서명할 수 없고, 서명 전 다시 협상하면 기존 초안 서명은 무효가 된다.
- 외부 입금 알림만으로는 잔액을 줄이지 않는다. 같은 입금·거래 요청을 중복 반영하지 않는다.
- 임의 서버 주소·API·실제 인증서명·근접 신호 성공·해시 확정값은 추가하지 않았다.
- 300만 원 이상 24시간 지연·서명 후 취소 등 미확정 정책은 현재 주 동선에서 확정 기능으로 제공하지 않는다.

## 브라우저에서 확인한 흐름

- 기존 크림·남색·카키와 수달 로고, 320px 홈 가로 넘침 없음.
- 외부 80,000원 알림 → 대여자 선택·반영 → 차용자 회차 잔액 20,000원 → 앱 상환 → 다음 회차 잔액 100,000원.
- 새 QR 약속 → 두 계정 확인 → 2회 첫 제안 → 3회 역제안 → 합의 → 두 계정 원문 끝까지 읽기·손글씨 서명 → 300,000원 대여 모의 송금.
- 2회차 100,000원을 72,000원/28,000원으로 분할 → 상대 수락 → 양쪽 원문 재열람·재서명 → 동일 문서번호의 v2 적용.
- 실행 중 콘솔 오류 없음. 도메인·타입·번들 결과는 전달 시 별도로 안내한다.
